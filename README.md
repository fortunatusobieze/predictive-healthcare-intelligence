# Predictive Healthcare Intelligence Programme

## Objective
Build:
1. Readmission risk prediction model
2. ED demand forecasting model
3. Leadership-facing Streamlit dashboard

## Tech Stack
Python, VS Code, MLflow, Streamlit, pandas, scikit-learn, XGBoost

## Folder Structure
- data/raw: source CSVs
- notebooks: EDA and experimentation
- src: reusable Python code
- outputs: figures, tables, models, reports
- dashboard: Streamlit app
